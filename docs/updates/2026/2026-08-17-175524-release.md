# 版本发布：Fix intermittent multiplayer room synchronization

- 时间：2026-08-17T17:55:24+08:00
- 类型：release
- 状态：success

## 摘要

Fixed stale and stopped room synchronization that intermittently hid joined players, blocked readiness, and prevented RPS resolution, then deployed the correction to production.

## 具体更新

- Reactivated polling when a client leaves and then creates, joins, or resumes another room, with session epochs preventing old requests from contaminating the new session.
- Serialized room polling, added bounded request timeouts, and rejected snapshots older than the current room revision or board version.
- Changed authenticated rate limiting from reverse-proxy socket IP to Logto subject so multiple players no longer share one room-view quota.
- Kept RPS submission state aligned with authoritative snapshots and added reuse-after-leave plus per-account rate-limit regression coverage.
