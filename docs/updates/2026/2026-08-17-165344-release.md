# 版本发布：Require Logto login for Gomoku multiplayer

- 时间：2026-08-17T16:53:44+08:00
- 类型：release
- 状态：success

## 摘要

Added PKCE login to the standalone Gomoku frontend and fail-closed Logto JWT verification to every multiplayer room endpoint, then deployed the site and room service to production.

## 具体更新

- Created a public Logto SPA integration with session-scoped browser tokens and login/logout UI while keeping AI play anonymous.
- Added ES384 JWKS verification, issuer/audience/client validation, access/ID token subject matching, and room credential binding to Logto subjects.
- Required passwords for spectators, restricted production API overrides, corrected empty HTTP/2 CORS preflight responses, and expanded public-repository secret-file ignores.
