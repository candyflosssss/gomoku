# 版本发布：发布独立五子棋 1.0.0

- 时间：2026-08-17T15:47:23+08:00
- 类型：release
- 状态：success

## 摘要

将五子棋从 Games 门户拆分为可独立开发、嵌入和部署的项目，并上线独立域名

## 具体更新

- 迁移棋核、页面、P2P 客户端、房间服务和三套检查脚本到独立仓库结构
- 新增运行时 API/ICE 配置、通用宿主生命周期适配层、零依赖开发服务器和静态构建流程
- 部署静态站和独立房间服务到 gomoku.candymo.com，并从原 Games API 路由解除绑定
